# Support & Resources

Need help integrating the Aegis RWA SDK, deploying the Soroban contracts, or understanding our architecture? We're here to help.

### 📖 Documentation
Your first stop should always be the documentation within the specific repository you are working with:
* `aegis-contracts/docs/`
* `aegis-sdk/docs/`
* `aegis-dashboard/docs/`

### 💬 Community & Discussion
* **Stellar Developer Discord:** Join the global community of Soroban developers at [discord.gg/stellardev](https://discord.gg/stellardev).
* **GitHub Discussions:** For broader architectural questions or feature requests, please use the GitHub Discussions tab on the relevant repository.

### 🐞 Bug Reports
If you have found a reproducible bug (that is **not** a security vulnerability), please open an issue in the appropriate repository using the provided Bug Report template.

*(For security vulnerabilities, please refer to our [Security Policy](SECURITY.md)).*
